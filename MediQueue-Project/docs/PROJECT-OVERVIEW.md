# Project Overview

**Project:** MediQueue - Clinic Appointment & Queue System  
**Technology:** Java Swing GUI, JDK 17, local text-file storage  
**Application type:** Desktop application

MediQueue provides separate sign-in roles for clinic staff and patients. It includes appointment and queue workflows, doctor scheduling, and local data persistence. The application can be compiled and run with the JDK without Tomcat or a database server.

## Build verification
The source is compiled with `javac --release 17` and packaged into `MediQueue.jar`.
